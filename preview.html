Underline & strikethrough

Each strike shows the same line three ways. The first two are the SAME underline; only text-decoration-skip-ink differs — on auto the browser cuts the rule around descenders, which on the small strikes reads as dashes. The bar below them is exactly one source pixel tall at the same zoom: both rules should match its thickness.

Strikethrough position is not settable: Firefox reads OS/2 yStrikeoutPosition from the font, Chrome ignores it and centres the line on half the x-height, and no CSS property can move it. Where the x-height is an even number of pixels (the 6, 12 and 14) Chrome lands it on a half pixel.
